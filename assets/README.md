## Tips for clean screenshots

1. Run the app: `python run.py`
2. Open `http://127.0.0.1:8050` in your browser
3. Set the chart type that looks best for each view (scatter/box/bar)
4. Use your browser's full-screen or zoom to fill the chart panel
5. Screenshot just the chart area (no browser chrome)
6. Recommended resolution: at least **1200 × 900 px** so they look sharp on the poster
7. Save as PNG

## Image display

If a file is missing, the poster shows a grey placeholder tile with the expected filename — the rest of the poster remains fully visible, so you can print a draft before all screenshots are ready.
